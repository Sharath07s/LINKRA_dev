# M1.4 FRONTEND API MIGRATION
**Status**: COMPLETE  
**Date**: 2026-08-27  

## Objective
Migrate the existing frontend from scattered/raw API calls (hardcoded `http://localhost:8000/api/v1` and `fetch`) to the centralized API client located at `frontend/src/lib/api-client.ts`. The goal is to establish ONE consistent frontend → backend communication layer before the SIH26189 UI/UX implementation begins.

## Actions Taken

### 1. API Client Refinement
- **File**: `frontend/src/lib/api-client.ts`
- **Action**: Added a response interceptor to globally handle `401 Unauthorized` responses. The interceptor triggers `useAuthStore.getState().logout()` to force a re-login when the JWT expires or becomes invalid.
- **Removed**: Deleted `frontend/src/lib/api.ts` since it duplicated the `api-client.ts` functionality but used `fetch` instead of `axios` and was entirely unused.

### 2. Service Migration
- **Auth Service** (`frontend/src/services/auth.service.ts`): Replaced raw `axios.post` pointing to `API_BASE_URL` with `apiClient.post("/auth/login")`.
- **Chat Service** (`frontend/src/services/chat.service.ts`): Removed manual `localStorage` JWT extraction logic. The file now uses `apiClient.post("/chat/")`, relying on the global request interceptor in `api-client.ts` for token injection.

### 3. Mass Component & Page Refactor
Identified 45+ files (Pages, Components, and Hooks) utilizing raw `fetch` and hardcoded `http://localhost:8000/api/v1` strings. 
- Replaced `fetch(URL)` with `apiClient.get(URL)` or `apiClient.post(URL)`.
- Replaced `.then(r => r.json())` with `.then(r => r.data)`.
- Replaced `if (res.ok)` with `if (res.status === 200)` (Axios automatically rejects promises for non-2xx responses).
- **Scope**: Changes affected the Command Wall, Officer Workspace, Executive Dashboard, Predictive Models, FIR Workspace, and Intelligence Fusion components.

### 4. Websockets Exclusion
- **File**: `frontend/src/components/Providers/RealtimeProvider.tsx`
- **Action**: Skipped modifying the `ws://localhost:8000` hardcoded string in the websocket connection setup. As per the constraints, websocket provider logic was explicitly omitted from this REST API refactoring milestone.

## Conclusion
The frontend application now utilizes a single source of truth for backend communication (`apiClient` powered by Axios). All authentication, headers, and error handling are centrally managed, making the app infrastructure ready for the upcoming SIH UI/UX phase.
