# LINKRA — M1.9 Anomaly Detection

## 1. Objective
Implement Milestone M1.9: Anomaly Detection. This milestone identifies structural and behavioral anomalies in the existing Neo4j intelligence graph (e.g., unusually high connectivity, relationship concentration, or isolated entities) using purely structural metrics, without relying on Neo4j GDS or inventing fake criminal data.

## 2. Architecture
- **Backend Service**: `Neo4jAnomalyService` in `backend/app/ai/neo4j/anomaly.py`.
- **API Endpoints**: REST router mapped to `/api/v1/graph/anomalies`.
- **Frontend Component**: Integrated into the node details side panel in `frontend/src/components/GraphNodeDetails.tsx`.
- **Database Engine**: Neo4j Aura Free (using only native bounded Cypher queries).
- **Source of Truth**: PostgreSQL remains the authoritative source.

## 3. Anomaly Types
- `HIGH_DEGREE`: Entities whose connectivity is statistically significantly higher than the graph baseline.
- `ISOLATED_ENTITY`: Entities with zero connections in the graph.
- `RELATIONSHIP_CONCENTRATION`: Entities whose relationships are unusually concentrated (e.g., >80%) in a single type, triggering only for entities with a degree of 5 or more.

## 4. Detection Algorithms & Mathematics
- **Baseline Calculation**: Calculates `mean(degree)` and `stDev(degree)` across the entire graph.
- **Minimum Population Threshold**: To avoid division by zero or nonsensical statistics, baseline calculations require a minimum graph population of `N=5`. If `total_nodes < 5`, the engine safely aborts and returns an `insufficient_data` status.
- **Composite Scoring**: 
  - For `HIGH_DEGREE`, a Z-score is calculated: `Z = (total_degree - mean) / stDev`. 
  - The anomaly score is normalized between 0.5 and 0.99 using `score = min(0.99, max(0.5, 0.5 + (z_score - 2) * 0.1))`.
  - For `RELATIONSHIP_CONCENTRATION`, the score maps directly to the percentage (e.g., 85% concentration = 0.85 score).

## 5. API Endpoints
- `GET /api/v1/graph/anomalies/top?limit=X`: Returns the highest-scoring structural anomalies globally. Bounded by a hard limit of 200.
- `GET /api/v1/graph/anomalies/{entity_id}`: Returns all structural anomalies specifically concerning a single entity.

## 6. Empty-State Behavior
- The API natively supports empty graphs, returning `{"status": "insufficient_data", "anomalies": []}`.
- The UI gracefully degrades, displaying "No structural anomalies detected." or "Analyzing structure..." without crashing or rendering `NaN`.

## 7. Performance Constraints
- All queries are strictly bounded native Cypher.
- Global scans (`/top`) use `WHERE degree > threshold` before returning to avoid loading the entire graph into Python memory.

- Upgrade to Neo4j GDS once the project outgrows the Aura Free tier to enable complex embedding-based outlier detection.
