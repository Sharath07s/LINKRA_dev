# M1.14 Reports / End-to-End Integration

## Objective
Implement a computed, read-only reporting layer that aggregates verified intelligence from PostgreSQL and Neo4j for a given investigation, and optionally uses AI to synthesize a narrative grounded strictly in that structured data.

## Implementation Details

### Data Sourcing & Architecture
The reporting layer creates no new PostgreSQL tables and performs no Neo4j write operations. It computes the report on-the-fly via the `ReportingService`:

1. **Investigation Base:** Fetched from PostgreSQL (`investigations` table).
2. **Entities:** Associated canonical entities fetched from PostgreSQL (`investigation_entities` → `canonical_entities`).
3. **Relationships:** Bounded query for relationships where both ends are in the entity list (`entity_relationships`).
4. **Evidence Provenance:** Mapped from `entity_candidates` and `ingestion_jobs` to provide file/page/row attribution.
5. **Structural Analytics:** `neo4j_analytics.get_degree()` for each entity.
6. **Anomalies:** `neo4j_anomaly.get_anomalies_for_entity()` for each entity.
7. **Potential Links:** `neo4j_predictions.get_potential_links_for_entity()` for each entity.

### Source Type Labeling
To prevent confusion between observed facts and AI predictions, every section of the report has an explicit `source_type`:
- `observed`: Direct PostgreSQL records and file provenance.
- `structural_analysis`: Derived from Neo4j graph structure (degrees, anomalies).
- `prediction`: Topology-based potential links.
- `ai_generated`: Synthesized narratives from LLM.

### AI Narrative Generation
The AI narrative is generated via the `FallbackManager` (M1.13) to ensure high availability (Groq → Gemini → OpenAI → DeepSeek).
- The LLM **never** accesses the raw database.
- It is provided only the structured JSON of the aggregated report.
- The prompt contains 9 strict rules prohibiting hallucination, fabrication, and stating potential links as facts.
- The UI includes a persistent disclaimer on the AI section.

### Frontend Integration
- Added `<ReportView>` component to the Investigation Workspace.
- Users can click "Generate Report" to view the structured data.
- Users can click "AI Narrative" to synthesize the executive summary.
- Users can click "Export JSON" to download the raw structured report data.
