# M1.11 INVESTIGATION WORKSPACE AUDIT

## 1. Existing Reusable Backend Components
- `backend/app/models/investigation.py`: Has `Investigation` and `InvestigationNote`.
- `backend/app/models/resolution.py`: Has `CanonicalEntity` (M1.5 resolution entities).
- `backend/app/api/v1/investigations.py`: Has base router, though mostly mock timeline endpoints.
- `backend/app/api/deps.py`: Role-based access control and active user checks.

## 2. Existing Reusable Frontend Components
- `frontend/src/app/investigations/[id]/page.tsx`: Existing layout with Case Header and Tabs.
- `frontend/src/app/knowledge-graph/page.tsx`: Contains `KnowledgeGraphContent`, which already handles Neo4j bounded querying (`focusId`), structural visualization, and embedding `GraphNodeDetails`.
- `frontend/src/components/GraphNodeDetails.tsx`: Contains M1.8 Analytics, M1.9 Anomalies, and M1.10 Potential Links!

## 3. Missing Capabilities (What to build)
- **Database**: No relationship currently exists between `Investigation` and `CanonicalEntity`. We need a many-to-many `InvestigationEntity` link table.
- **Backend API**: Endpoints to GET, POST, and DELETE entities associated with a specific investigation.
- **Frontend UI**:
  - A mechanism to add an existing entity to the investigation.
  - A horizontal list/panel showing the entities added to the current investigation.
  - Integration of the existing `KnowledgeGraphContent` into the Investigation Workspace tabs (currently it displays an EmptyState).
  
## 4. Proposed Minimal Integration
- Do NOT rewrite `GraphNodeDetails` or the Neo4j backend.
- Introduce `InvestigationEntity` SQLAlchemy model.
- Add `/api/v1/investigations/{id}/entities` in `investigations.py`.
- Extract the core `KnowledgeGraphContent` from `knowledge-graph/page.tsx` so it can be embedded directly into `investigations/[id]/page.tsx` (specifically inside the `Network` tab).
- When a user selects an entity from the Investigation Entities list, we set `focusId` and let the existing graph infrastructure handle M1.7 - M1.10 display automatically!
