# LINKRA — M1.8 Graph Analytics & Network Discovery

## Overview
This document outlines the Graph Analytics layer for the LINKRA platform, completing Milestone M1.8. The goal is to provide quantitative network analysis (e.g., node degree, relationship distributions, shortest paths) directly on the intelligence graph.

## Neo4j Aura Free Limitations & Workarounds
Due to the absence of the Neo4j Graph Data Science (GDS) library on Aura Free tier:
1. **Degree Centrality:** Calculated using native Cypher degree counts (`count(r)`).
2. **Shortest Path:** Handled using the `shortestPath()` Cypher function, bounded with a `max_depth` to prevent long-running queries from timing out the free tier.
3. **Component Detection (Local Reachability):** Calculated by traversing from a focal node up to a depth limit, counting unique reachable nodes, substituting full Louvain/Community Detection.

## API Endpoints
All graph analytics endpoints are located under `/api/v1/graph/analytics/`:
- `GET /degree/{entity_id}`: Returns `total_degree`, `in_degree`, and `out_degree`.
- `GET /centrality/degree`: Returns top entities ranked by degree.
- `GET /shortest-path?source=X&target=Y`: Bounded shortest path up to `max_depth` (default 4).
- `GET /distribution/{entity_id}`: Returns counts of relationships by `rel_type`.
- `GET /component/{entity_id}`: Returns bounded component size representing local reachability.

## Frontend Integration
The analytics are deeply integrated into the node inspection side-panel in `/knowledge-graph`.
When a node is selected, parallel requests are dispatched for:
- Connectivity Metrics (Total, In, Out Degree)
- Relationship Type Distribution
These add analytical depth without cluttering the main interactive constellation graph.
