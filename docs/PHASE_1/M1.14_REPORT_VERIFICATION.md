## Quality Constraints Adhered To
1. **No Fake Data:** If the database has no records, the report reflects empty datasets truthfully.
2. **Single Source of Truth:** PostgreSQL is used exclusively for entities, relationships, and evidence provenance.
3. **No Unbounded Queries:** Neo4j graph analytics and predictions are bounded to the exact entities associated with the investigation.
4. **No LLM Hallucinations:** The LLM is supplied with structured JSON context and given 9 strict formatting rules against fabricating intelligence.
