## 4. GDS Projection Mechanism
The graph is projected using `CALL gds.graph.project('linkra_community_graph', '*', '*', { undirectedRelationshipTypes: ['*'], memory: '2GB' })`. This correctly captures all real entities and relationships in an undirected format required for robust community detection. Projections are cleaned up cleanly in a `finally` block or right after computation to prevent namespace collisions.
